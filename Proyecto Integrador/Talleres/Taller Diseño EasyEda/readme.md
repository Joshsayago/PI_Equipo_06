# 🔌 Taller de Diseño de PCB

Este repositorio contiene el desarrollo del **Taller de Diseño de PCB**, realizado como parte de las actividades académicas de la **Universidad Peruana Cayetano Heredia (UPCH)**.

## 📌 Descripción

Durante este taller se desarrolló el proceso de diseño de una **placa de circuito impreso (PCB)**, comenzando desde la elaboración del esquemático hasta la distribución y conexión de los componentes en la placa.

El objetivo principal fue aprender y aplicar conceptos básicos relacionados con:

- Diseño de esquemáticos.
- Selección de componentes y footprints.
- Conexión entre componentes.
- Diseño y distribución de la PCB.
- Ruteo de pistas.
- Uso de planos de cobre y GND.
- Verificación de reglas de diseño (DRC).
- Visualización del diseño final en 3D.

## 📂 Contenido

El repositorio contiene los archivos correspondientes a:

- Esquemáticos desarrollados durante el taller.
- Archivos necesarios para la fabricación, cuando corresponda.
- Descripcion de lo hecho en el PCB.

## 🎯 Resultado

Como resultado del taller se obtuvo una PCB diseñada y ruteada, verificando las conexiones entre los componentes y aplicando las reglas básicas necesarias para preparar el diseño para su posterior fabricación.
