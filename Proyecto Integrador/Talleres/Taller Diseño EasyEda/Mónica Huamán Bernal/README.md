JUSTIFICACIÓN
Se diseñó una PCB basada en un microcontrolador, encargado de recibir y procesar las señales provenientes de los sensores que se incorporarán al sistema. La información procesada será mostrada mediante una pantalla OLED, permitiendo visualizar los parámetros medidos. La placa también incorpora las conexiones de alimentación de 3.3 V y GND para garantizar el funcionamiento de los componentes.
