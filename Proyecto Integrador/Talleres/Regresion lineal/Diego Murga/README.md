# 📈 Regresión Lineal — Diego Murga

Esta carpeta contiene el trabajo realizado por **Diego Murga** durante el taller de **Regresión Lineal**, enfocado en el análisis y predicción del consumo de energía.

## 📊 Trabajo realizado

Durante el taller se desarrollaron principalmente los siguientes puntos:

- **Análisis de correlación:** permitió identificar la relación entre las variables y determinar cuáles están más asociadas con el consumo de energía.
- **Valores reales vs. predichos:** permitió comparar las predicciones del modelo con los datos reales.
- **Análisis de residuos:** se utilizó para observar los errores de predicción y evaluar el comportamiento del modelo.
