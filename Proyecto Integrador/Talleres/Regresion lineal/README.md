# 📈 Taller de Regresión Lineal – Semana 5 
En este taller se trabajó con **Regresión Lineal** para analizar y predecir el **consumo de energía** a partir de diferentes variables. 
## 📊 Análisis de datos 
Se analizaron variables como: 
- Temperatura
- Humedad
- Carga
- Horas de operación
- Consumo de energía

Se utilizaron gráficos para observar la relación entre las variables y el consumo energético.

## 🔗 Correlación
Se generó una **matriz de correlación** para identificar qué variables presentan una mayor relación con el consumo de energía.

## 📌 Conclusión
El taller permitió comprender el proceso básico de una regresión lineal:
**Analizar datos → Identificar relaciones → Entrenar → Predecir → Evaluar**
Se utilizaron herramientas como **Pandas, NumPy, Matplotlib, Seaborn y Scikit-learn**.
