# CNN - Diego Murga

Este proyecto utiliza una Red Neuronal Convolucional (CNN) para clasificar imágenes de comida rápida.

Se realizó:

- Entrenamiento de una CNN desde cero.
- Evaluación con Accuracy y ROC-AUC.
- Aplicación de Data Augmentation.
- Comparación entre el modelo original y el modelo con aumentos de datos.

## Resultado

El Data Augmentation produjo una mejora mínima en Accuracy, pero una ligera reducción en ROC-AUC, por lo que no se observó una mejora general significativa.
